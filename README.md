# 🎬 ZenCine - Rạp Phim Trực Tuyến Đẳng Cấp

Nền tảng xem phim trực tuyến Full HD mượt mà, tốc độ cao, không quảng cáo pop-up rác, tích hợp giao thức phát HLS Adaptive Bitrate Streaming (.m3u8).

## 🚀 Công Nghệ
- **Frontend**: React 19 + Vite 8 + TypeScript
- **Styling**: Tailwind CSS + Glassmorphism Cinema UI
- **Icons**: Lucide Icons
- **Video Engine**: Artplayer + Hls.js
- **Nguồn Dữ Liệu**: PhimAPI / KKPhim (Miễn phí, cập nhật liên tục)

## 💻 Cách Khởi Chạy
```bash
# Cài đặt thư viện (nếu clone mới)
npm install

# Chạy môi trường phát triển
npm run dev
```

Truy cập: [http://localhost:3001](http://localhost:3001)
